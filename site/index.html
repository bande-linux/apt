Bande

APT repository for the Bande desktop on Debian 14 (forky), for amd64 and arm64. One suite per Debian release, named by its codename; today forky.

Install

On Debian 14 (forky). The packages are built against forky and do not install on Debian 13 (trixie).

1. Download the keyring and your Debian release's source package from the latest GitHub release, and install both:

cd /tmp
suite=$(. /etc/os-release && echo "$VERSION_CODENAME")
wget https://github.com/bande-linux/apt/releases/latest/download/bande-archive-keyring.deb \
     "https://github.com/bande-linux/apt/releases/latest/download/bande-apt-source-$suite.deb"
sudo apt install ./bande-archive-keyring.deb "./bande-apt-source-$suite.deb"

This adds /etc/apt/sources.list.d/bande.sources:

Types: deb
URIs: https://bande-linux.github.io/apt
Suites: forky
Components: main
Signed-By: /usr/share/keyrings/bande-archive-keyring.pgp

2. Install the desktop:

sudo apt update
sudo apt install bande-desktop

This installs the whole system: the desktop, its login window, NetworkManager, PipeWire and the everyday apps. If another display manager is installed, apt asks which one to start. Updates arrive with sudo apt upgrade.

Packages

The one component, main (amd64, arm64), holds the desktop, the browser, the repository packages and the optional apps, each installed on its own with sudo apt install bande-<name>.

Remove

sudo apt purge bande-apt-source bande-archive-keyring

Signing key

Packages and indices are signed with the Bande archive key (key.asc), fingerprint:

@FINGERPRINT@

If a machine was offline through a key change and apt update reports a signature error, repeat step 1.
