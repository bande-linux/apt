Bande

APT repository for the Bande desktop on Debian testing, amd64 and arm64. One rolling suite: every tagged desktop release, and the Mac mini kernel as Debian testing moves.

Install

On Debian testing (packages here are built against testing and do not install on Debian 13).

1. Download the keyring and the source package from the latest GitHub release, and install both:

cd /tmp
wget https://github.com/bande-linux/apt/releases/latest/download/bande-archive-keyring.deb \
     https://github.com/bande-linux/apt/releases/latest/download/bande-apt-source.deb
sudo apt install ./bande-archive-keyring.deb ./bande-apt-source.deb

This adds /etc/apt/sources.list.d/bande.sources:

Types: deb
URIs: https://bande-linux.github.io/apt
Suites: rolling
Components: main apple
Signed-By: /usr/share/keyrings/bande-archive-keyring.pgp

2. Install the desktop:

sudo apt update
sudo apt install bande-desktop

This installs the whole system: the desktop, its login window, NetworkManager, PipeWire and the everyday apps. If another display manager is installed, apt asks which one to start. Updates arrive with sudo apt upgrade.

Components

main (amd64, arm64) holds the desktop, the repository packages and the optional apps, each installed on its own with sudo apt install bande-<name>. apple (arm64) holds the Mac mini M2 kernel, built from Debian's kernel with the Apple patches, and bande-os-apple; it carries the newest two kernel versions.

Remove

sudo apt purge bande-apt-source bande-archive-keyring

Signing key

Packages and indices are signed with the Bande archive key (key.asc), fingerprint:

@FINGERPRINT@

If a machine was offline through a key change and apt update reports a signature error, repeat step 1.
