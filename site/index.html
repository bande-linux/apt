Unbound

APT repository for the Unbound desktop on Debian 13 (trixie), arm64.

Install

Choose a channel. Release carries tagged versions only. Testing carries the newest build of every change merged to main. Your machine then updates from that channel alone.

1. Download the keyring and the channel package from the latest GitHub release, and install both. For the release channel:

cd /tmp
wget https://github.com/unbound-linux/apt/releases/latest/download/unbound-archive-keyring.deb \
     https://github.com/unbound-linux/apt/releases/latest/download/unbound-apt-source.deb
sudo apt install ./unbound-archive-keyring.deb ./unbound-apt-source.deb

For testing, use unbound-apt-source-testing.deb in both places.

2. Install the desktop:

sudo apt update
sudo apt install unbound-desktop

Log out and choose Unbound at the login screen. Updates arrive with sudo apt upgrade.

Switch channel

sudo apt install unbound-apt-source-testing   # to testing
sudo apt install unbound-apt-source           # to release

Going back to release does not downgrade anything: packages keep their testing version until a release passes it.

Remove

sudo apt purge unbound-apt-source unbound-apt-source-testing unbound-archive-keyring

Signing key

Packages and indices are signed with the Unbound archive key (key.asc), fingerprint:

@FINGERPRINT@

If a machine was offline through a key change and apt update reports a signature error, repeat step 1.
