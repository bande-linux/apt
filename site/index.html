Unbound

APT repository for the Unbound desktop on Debian testing, amd64 and arm64. One rolling suite: every tagged desktop release, and the Mac mini kernel as Debian testing moves.

Install

On Debian testing (packages here are built against testing and do not install on Debian 13).

1. Download the keyring and the source package from the latest GitHub release, and install both:

cd /tmp
wget https://github.com/unbound-linux/apt/releases/latest/download/unbound-archive-keyring.deb \
     https://github.com/unbound-linux/apt/releases/latest/download/unbound-apt-source.deb
sudo apt install ./unbound-archive-keyring.deb ./unbound-apt-source.deb

This adds /etc/apt/sources.list.d/unbound.sources:

Types: deb
URIs: https://unbound-linux.github.io/apt
Suites: rolling
Components: main apple
Signed-By: /usr/share/keyrings/unbound-archive-keyring.pgp

2. Install the desktop:

sudo apt update
sudo apt install unbound-desktop

Log out and choose Unbound at the login screen. Updates arrive with sudo apt upgrade.

Components

main (amd64, arm64) holds the desktop, unbound-os and the repository packages. apple (arm64) holds the Mac mini M2 kernel, built from Debian's kernel with the Apple patches, and unbound-os-apple; it carries the newest two kernel versions.

Remove

sudo apt purge unbound-apt-source unbound-archive-keyring

Signing key

Packages and indices are signed with the Unbound archive key (key.asc), fingerprint:

@FINGERPRINT@

If a machine was offline through a key change and apt update reports a signature error, repeat step 1.
