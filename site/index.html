Bande

APT repository for the Bande desktop on Debian 14 (forky), for amd64 and arm64. One suite per Debian release, named by its codename; today forky.

Install

The install steps are at bande-linux.github.io/debian. They add /etc/apt/sources.list.d/bande.sources:

Types: deb
URIs: https://bande-linux.github.io/apt
Suites: forky
Components: main
Signed-By: /usr/share/keyrings/bande-archive-keyring.pgp

Packages

The one component, main (amd64, arm64), holds the desktop, the browser, the repository packages and the apps, each installed on its own with sudo apt install bande-<name>.

Remove

sudo apt purge bande-apt-source bande-archive-keyring

Signing key

Packages and indices are signed with the Bande archive key (key.asc), fingerprint:

@FINGERPRINT@

If a machine was offline through a key change and apt update reports a signature error, repeat the first install step.
